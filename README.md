Welcome to my **CSE1102** repository! This archive contains my foundational C programming exercises, lab assignments, and basic problem-solving codes completed during my **1st Year, 1st Semester** as a Computer Science and Engineering (CSE) undergraduate student.

Every big journey starts with strong fundamentals. Mastering structured programming in C is my very first step toward building a solid base in **Data Structures, Algorithms, and Software Engineering**. ### 📂 Topics Covered
- **Basic Input/Output & Operators:** Variables, Data Types, and Arithmetic Logic
- **Conditional Statements:** `if-else`, Nested Conditions, and `switch-case`
- **Loops & Pattern Printing:** `for`, `while`, `do-while`, and Star/Number Patterns
- **Arrays & Strings:** 1D/2D Arrays, Searching, Sorting, and String Manipulation
- **Functions & Recursion:** Modular Programming and Recursive Problem Solving
- **Pointers & Structures:** Memory Concepts and User-Defined Data Types
